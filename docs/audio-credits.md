# Музыка меню

В меню используется один выбранный human-made трек — **Our Mountain — RPG**. Он загружается по внешней ссылке, поэтому для его прослушивания нужен интернет.

- **Our Mountain — RPG** — Eric Matyas / Soundimage.org.
- Страница источника и атрибуции: https://soundimage.org/fantasywonder/
- Используемая loop-версия: https://soundimage.org/wp-content/uploads/2018/10/Our-Mountain_v003_Looping.mp3

На странице Soundimage отдельно указаны looping и non-looping версии трека. В приложении используется looping-версия, чтобы при повторе не было длинной паузы в конце.

## Музыка боя

- **Preparing for Battle** — Eric Matyas / Soundimage.org.
- Страница источника и атрибуции: https://soundimage.org/epic-battle/
- Используемый loop-источник: https://soundimage.org/wp-content/uploads/2020/06/Preparing-for-Battle.mp3

Трек помечен автором как looping и Royalty-Free; для использования сохраняется требование атрибуции Soundimage.

## Локальные звуки боя

Сгенерированные короткие WAV-эффекты хранятся в `public/audio`:

- `battle-hit.wav` — обычный удар;
- `battle-double.wav` — двойной удар;
- `battle-magic.wav` — лечение;
- `battle-item.wav` — лечебная трава;
- `battle-miss.wav` — промах;
- `battle-victory.wav` — победа;
- `battle-defeat.wav` — поражение.
